# 一个小例子

你们公司近期上线了一个日志聚合系统，它是一个统一的日志采集、存储和查询平台，可在一个前端页面排查所有服务的日志。

你作为一个AI技术的狂热爱好者，已经不满足于人工排查日志问题了。于是，你为该系统适配了一个MCP，可以调用该服务的开放端口，查询，并让AI分析错误日志。

你的MCP拥有如下两个工具

![image](assets/1774570034317-da731498-faa8-432f-92e2-ea745ab35319.png)

当你在测试查询日志时发现一个痛点，日志级别必须填，但是还不知道填什么，于是你有了新的需求——需要进行输入限制。例如：必填/非必填；候选值下拉列表。

# 问题出现的原因

按照之前学习的，你的这个Tool代码应该是这样写的。

```go
mcp.AddTool(s, &mcp.Tool{
    Name:        "query-logs",
    Description: "查询日志",
}, queryLogsTool)
```

```go
type queryLogsInput struct {
	ServiceName string `json:"service_name" jsonschema:"服务名称"`
	LogLevel    string `json:"log_level" jsonschema:"日志级别"`
	TimeRange   string `json:"time_range" jsonschema:"时间范围"`
}

type queryLogsOutput struct {
	Logs []string `json:"logs" jsonschema:"日志"`
}

func queryLogsTool(ctx context.Context, req *mcp.CallToolRequest, in queryLogsInput) (*mcp.CallToolResult, queryLogsOutput, error) {
	return nil, queryLogsOutput{
		Logs: []string{"log1", "log2", "log3"},
	}, nil
}
```

`LogLevel`字段的JSON序列化标签为`json:"log_level"`。若客户端未输入内容导致字段为空，JSON反序列化将会报错。

# 非必填设置

按照上述分析，为`json:"log_level"`增加空则忽略的标签即可。`json:"log_level,omitempty" `

# 候选值

## 单选候选值

在[快速开始](%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B.md)我们了解过，SDK 会根据 `In` 的类型推断/生成 JSON Schema，作为该工具的 `inputSchema`；若在 `mcp.Tool.InputSchema` 里显式传入 schema，可以**覆盖**这个默认。

现在我们需要精细化控制，就需要自定义`mcp.Tool.InputSchema`。

方便后续管理，我们可以搞一个 schema.go 文件，用来存放自定义schema。

```go
package main

import (
	"log"

	"github.com/google/jsonschema-go/jsonschema"
)

// queryLogsAllowedLogLevels 由服务端定义，并写入 tools/query-logs 的 inputSchema.properties.log_level.enum。
var queryLogsAllowedLogLevels = []any{"debug", "info", "warn", "error"}

// 自定义的InputSchema
var queryLogsInputSchema *jsonschema.Schema

func init() {
	s, err := jsonschema.For[queryLogsInput](nil)
	if err != nil {
		log.Fatalf("query-logs 输入 schema: %v", err)
	}
	if p := s.Properties["log_level"]; p != nil {
		p.Enum = append([]any(nil), queryLogsAllowedLogLevels...)
	}
	queryLogsInputSchema = s
}
```

现在添加工具时，将`Tool.InputSchema`指定为 刚刚自定义的就好了。

```go
mcp.AddTool(s, &mcp.Tool{
	Name:        "query-logs",
	Description: "查询日志",
	InputSchema: queryLogsInputSchema, // 由 不设置 改为 设置自定义的
}, queryLogsTool)
```

## 多选候选值

```go
var queryLogsAllowedLogLevels = []any{"debug", "info", "warn", "error"}

var queryLogsInputSchema *jsonschema.Schema

func init() {
	s, err := jsonschema.For[queryLogsInput](nil)
	if err != nil {
		log.Fatalf("query-logs 输入 schema: %v", err)
	}
	if p := s.Properties["log_levels"]; p != nil {
		p.UniqueItems = true
		if p.Items == nil {
			p.Items = &jsonschema.Schema{Type: "string"}
		}
		p.Items.Enum = append([]any(nil), queryLogsAllowedLogLevels...)
	}
	queryLogsInputSchema = s
}
```
