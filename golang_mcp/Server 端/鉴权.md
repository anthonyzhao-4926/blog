> 鉴权没有什么特性可说，单独作为一篇是先强调其重要性。

关于鉴权，本框架专门提供了两个包

> - The [github.com/modelcontextprotocol/go-sdk/auth](https://pkg.go.dev/github.com/modelcontextprotocol/go-sdk/auth) package provides some primitives for supporting OAuth.
> - The [github.com/modelcontextprotocol/go-sdk/oauthex](https://pkg.go.dev/github.com/modelcontextprotocol/go-sdk/oauthex) package provides extensions to the OAuth protocol, such as ProtectedResourceMetadata.

下边实现一个简单的Bear Token鉴权示例

# 一个小例子

```go
// MCP Streamable HTTP 示例：在交给 MCP handler 之前校验 Bearer Token（鉴权层与协议层分离）。
package main

import (
	"context"
	"crypto/subtle"
	"log"
	"net/http"
	"os"
	"strings"

	"github.com/modelcontextprotocol/go-sdk/mcp"
)

// 未设置 MCP_AUTH_TOKEN 时使用该占位值，仅便于本地试跑；生产环境必须设置强随机密钥。
const defaultDemoToken = "demo-change-me"

type pingToolOutput struct {
	OK string `json:"ok" jsonschema:"状态"`
}

func pingTool(_ context.Context, _ *mcp.CallToolRequest, _ any) (*mcp.CallToolResult, pingToolOutput, error) {
	return nil, pingToolOutput{OK: "authenticated"}, nil
}

// bearerAuth 要求请求头 Authorization: Bearer <token>，与 MCP_AUTH_TOKEN 一致（或默认 demo 值）。
func bearerAuth(expected string, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if expected == "" {
			http.Error(w, "server misconfigured: empty auth token", http.StatusInternalServerError)
			return
		}
		raw := r.Header.Get("Authorization")
		const prefix = "Bearer "
		if !strings.HasPrefix(raw, prefix) {
			w.Header().Set("WWW-Authenticate", `Bearer realm="mcp"`)
			http.Error(w, "missing or invalid Authorization scheme", http.StatusUnauthorized)
			return
		}
		got := raw[len(prefix):]
		if len(got) != len(expected) || subtle.ConstantTimeCompare([]byte(got), []byte(expected)) != 1 {
			w.Header().Set("WWW-Authenticate", `Bearer realm="mcp"`)
			http.Error(w, "invalid token", http.StatusUnauthorized)
			return
		}
		next.ServeHTTP(w, r)
	})
}

func main() {
	token := strings.TrimSpace(os.Getenv("MCP_AUTH_TOKEN"))
	if token == "" {
		token = defaultDemoToken
		log.Printf("警告: 未设置 MCP_AUTH_TOKEN，使用内置演示 token，生产环境请勿如此。当前 Bearer 值请见常量 defaultDemoToken 或启动日志下一行。")
	}

	srv := mcp.NewServer(&mcp.Implementation{Name: "http-auth-demo", Version: "0.1.0"}, nil)
	mcp.AddTool(srv, &mcp.Tool{
		Name:        "ping",
		Description: "鉴权通过后调用，用于验证身份已生效",
	}, pingTool)

	mcpHandler := mcp.NewStreamableHTTPHandler(func(*http.Request) *mcp.Server { return srv }, nil)
	// 在mcpHandler基础上封装一层
    handler := bearerAuth(token, mcpHandler)

	addr := "127.0.0.1:8000"
	log.Printf("MCP Streamable HTTP (with Bearer auth) on http://%s/", addr)
	if err := http.ListenAndServe(addr, handler); err != nil {
		log.Fatal(err)
	}
}
```

# 代码解释

## Handler 封装鉴权

```go
    // 在mcpHandler基础上封装一层
    handler := bearerAuth(token, mcpHandler)
```

将鉴权封装在 handler 上，每个向该MCP发送的请求都能够进行鉴权。

## 为什么要 `ConstantTimeCompare`

- 普通 `got != expected` 在**逐字节比较时**，往往在发现第一个不同字节后就返回，比较耗时和「第几个字节错了」有关。  
- **计时攻击**：攻击者大量尝试时，有时能从响应时间推测出前缀是否猜对（对高敏感场景才值得防）。  
- `subtle.ConstantTimeCompare`：在**长度相同**时按固定流程比较，避免这种侧信道；前面 `len(got) != len(expected)` 先挡掉长度不同的情况（长度不同时 `ConstantTimeCompare` 直接返回 0，这里短路掉也能少一次分配）。

对「随便一个 demo 鉴权」来说，用 `==` 也常被接受；这里用 `subtle` 是偏稳妥的写法。
