## claude agent sdk

> 官方文档：https://docs.claude.com/en/api/agent-sdk/overview

案例驱动地讲 claude agent sdk 怎么用：每一篇都从一个具体需求出发——「要流式输出」「要展示思考过程」「要前端知道 subagent 跑到哪了」——然后看这个需求在消息流里长什么样、要调哪些参数。

### 读完能做到什么

**能**：用 agent sdk 把一个聊天界面从零搭起来——发消息拿回复、改成流式渲染、把 thinking 单独展示、呈现工具调用与 subagent 进度，并配好权限与运行时审批。

**不能**：不介绍安装与鉴权（假定你已经按官方 quickstart 跑通过一次调用）；不涉及前端框架选型；[Turn](08-turn.md) 一篇目前只有一张截图，文字待补。

### 前置假设

- 会用 TypeScript / Node。
- 已经跑通过一次 agent sdk 调用，知道 `query()` 大概长什么样。
- 不需要预先了解 Anthropic Messages API 的消息结构。

### 一条主线

按顺序读就行，每篇结尾有下一篇的链接。这条线是**跟着需求长出来的**：每一步都在上一次的基础上加一件事。

1. [纯聊天](01-纯聊天.md)——发一条消息拿完整回复；消息结构长什么样
2. [流式输出](02-流式输出.md)——改成边生成边显示；多出来的标志和「块」
3. [展示思考过程](03-展示思考过程.md)——把 thinking 块拆出来单独渲染
4. [工具调用过程](04-工具调用过程.md)——工具调用与结果的消息形态，以及 turn 的由来
5. [agent 进度跟踪](05-agent%20进度跟踪.md)——subagent 的消息归属与进度转发
6. [权限配置](06-权限配置.md)——「货架有哪些工具」与「哪些能被放行」两层
7. [权限审批](07-权限审批.md)——用 `canUseTool` 在运行时接管审批
8. [Turn](08-turn.md)——回到最基础的概念：一个来回的边界（**待补**）
