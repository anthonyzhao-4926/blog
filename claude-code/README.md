## claude-code

> 官方文档：https://code.claude.com/docs/zh-CN/overview

claude code 自己的官方文档写的太不适合人类阅读了，很多地方他都想当然地认为你知道，中文也是机器生硬地翻译。

本教程只涉及 claude code 各组件各工具如何使用，不涉及如何才能用的更好。用的更好应该是属于AI工程相关内容，我准备独立出来撰写。

### 读完能做到什么

**能**：认清 Claude Code 的组件构成，会用它的内置工具、斜杠命令、记忆系统（CLAUDE.md 与 `.claude/rules/`）、Skills 和 Subagent，并知道每个组件会占用多少上下文。

**不能**：不教你怎么把 Claude Code 用得更好——提示词工程、任务拆解、工作流设计属于 AI 工程，那是另一个专栏的事；也不逐个覆盖官方文档里的参数。

### 前置假设

- 装好并跑起来过 Claude Code。
- 不需要预先了解它的组件体系。

### 一条主线

按顺序读就行，每篇结尾有下一篇的链接。

全篇有一个贯穿的约束：**上下文窗口**。上面那些组件本质上都在抢同一块地方，所以每篇都会提一句「它怎么少占上下文」。

1. [宏观认识 Claude Code](01-宏观认识Claude%20code.md)——有哪些组件，上下文窗口为什么是核心约束
2. [Claude 可调用的工具](02-Claude可调用的工具.md)——内置工具总览与核心工具详解
3. [斜杠命令](04-斜杠命令.md)——控制会话、上下文与模型；篇幅长，也可以只当查询表
4. [记忆机制](05-记忆机制.md)——CLAUDE.md、`.claude/rules/`、自动记忆
5. [Skills](06-Skills.md)——把可复用的工作流封装成按需加载的文件夹
6. [Subagent](07-Subagent.md)——定义并调用子代理，把支线任务挪出主上下文
7. [effort、设置优先级与模型](09-effort、设置优先级与模型.md)——速查性质，也可以直接跳去查

### 关于参考目录

本专栏**没有** `参考/` 子目录，这是有意的：[斜杠命令](04-斜杠命令.md)和[Claude 可调用的工具](02-Claude可调用的工具.md)本身就是查阅型内容，但都是**已发布**的文章，挪位置会让线上链接失效；而且斜杠命令那篇剪切自他人文章，不适合大改。所以它们留在主线里，靠上面的任务索引表满足「只想查一条」的需求。

什么时候该有 `参考/`：查到才用、且和读物放在一起会互相干扰的内容。参考 [linux 命令入门](../linux%20命令入门/README.md) 的说明。
