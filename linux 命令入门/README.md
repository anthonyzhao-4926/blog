## linux 命令入门

> 面向「学校没教、工作要用」的人：把 Linux 从零用起来。

### 读完能做到什么

**能**：在 Linux 上完成日常工作——浏览和操作目录文件、看懂权限位、搜索文件、用 vim 改配置文件、写带变量和判断的 shell 脚本、用 grep/sed/awk 处理文本。

**不能**：不讲内核原理、性能调优、运维体系；不覆盖每个命令的全部参数（那本来就该查手册）；不涉及 shell 高级编程。

### 前置假设

- 手上有一台能敲命令的 Linux（虚拟机、WSL、服务器都行）。
- 不需要编程基础。

### 为什么没有「参考」目录

其他专栏有 `参考/` 子目录放查阅型内容，这个专栏没有——因为**它的主体本来就是速查表**。`linux 常用命令` 本身就是那张卡片，忘了参数直接去查它即可，再分出一个参考目录只会让同一个命令有两个家。

参考目录只在「有明确的查阅型内容，且需要和读物分开」时才值得存在。
